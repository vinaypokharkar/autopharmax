Drug Response Prediction System

Project Overview

  • Goal: Predict cancer drug response (IC50 values) using machine learning.
  • Target Variable: LN(IC50) - Natural logarithm of concentration for 50% inhibition.
  • Application: Personalized cancer treatment recommendations.
