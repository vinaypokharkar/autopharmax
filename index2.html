Project Overview

Goal: To accurately predict cancer drug response (IC50 values) using machine learning.

  • 🎯 Target Variable: LN(IC50) - The natural logarithm of the drug concentration needed to inhibit 50% of cancer cell growth.
  • 🏥 Application: To provide personalized cancer treatment recommendations and accelerate drug discovery.

Datasets Used

Three core datasets were integrated to build our models:

1. GDSC Dataset (35MB)

Genomics of Drug Sensitivity in Cancer database. Contains drug response data across numerous cancer cell lines.

2. Cell Lines Details (115KB)

Provides metadata for cancer cell lines, including tissue type and cancer classification.

3. Merged Dataset (37MB)

A combined and cleaned dataset with 166,644 samples and 31 features.

Machine Learning Algorithms

We experimented with both traditional and deep learning approaches.

Traditional ML Models

  • Linear Regression (Baseline)
  • ElasticNet
  • Random Forest
  • XGBoost

Deep Learning Model

  • Artificial Neural Network (ANN)

Technical Implementation

Our end-to-end pipeline involved three key stages:

1. Data Preprocessing

  • Stratified Split (60/20/20) & StandardScaler
  • PCA for dimensionality reduction & One-hot encoding

2. Hyperparameter Tuning

Optimized key parameters for Random Forest and XGBoost to maximize performance.

3. Model Deployment

  • Developed an interactive Streamlit Web App.
  • Models saved using Pickle for persistence.

Key Insights
